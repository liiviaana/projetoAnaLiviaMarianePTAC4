Tema do projeto

Avaliação de Pratos: um site onde a pessoa cadastra os pratos que experimentou, dá uma nota de 1 a 5 e escreve um comentário. Os pratos ficam separados por categoria.

Resumo do problema

Quando a gente come em restaurantes ou testa receitas, acaba esquecendo quais pratos gostou e quais não quer repetir. Sem um registro, fica difícil comparar e escolher o que pedir ou fazer de novo. O projeto resolve isso com um lugar simples para anotar a nota e a opinião sobre cada prato e ver a média das notas.

Requisitos funcionais
RF01: cadastrar uma avaliação com nome do prato, categoria, nota (1 a 5) e comentário.
RF02: listar todos os pratos avaliados.
RF03: remover uma avaliação.
RF04: filtrar os pratos por categoria.
RF05: mostrar a média das notas dos pratos que estão na lista.
RF06: manter as avaliações salvas quando o navegador for fechado e aberto de novo.
Requisitos não funcionais
RNF01: a interface deve ser simples, para qualquer pessoa conseguir usar sem explicação.
RNF02: a página deve responder rápido às ações do usuário.
RNF03: deve funcionar nos navegadores mais usados (Chrome, Firefox e Edge).
RNF04: o layout deve se ajustar a telas de computador e de celular.
RNF05: os textos digitados pelo usuário devem ser tratados antes de aparecer na tela.
RNF06: o código deve ficar separado em HTML, CSS e JavaScript e ser versionado no GitHub.
Tecnologias

HTML, CSS e JavaScript.
